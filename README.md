# ETH 评分模拟盘

基于五项技术指标共振评分的 ETH/USDT 模拟交易监控页面。行情来自 OKX 公共 API，账户和交易记录仅保存在浏览器 `localStorage`，不会连接交易账户或提交真实订单。

## 交易规则

- 初始资金：10,000 USDT
- 多头：评分 ≥ +4 且 ADX > 10 时买入现货；评分 ≤ 0 时平仓
- 空头：评分 ≤ -3 且 ADX > 25 时开 1× 永续；评分 ≥ -4 时平仓
- 指标投票：ADX + DI、MACD、布林带中轨、SAR、EMA20/EMA60
- 费用：现货 taker 0.10%，永续 taker 0.05%，暂不计资金费
- 当前预置持仓：2026-08-17 现货多单，入场价 1,843.69 USDT

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev -- --hostname 127.0.0.1 --port 3000
```

浏览器打开 <http://127.0.0.1:3000/>。

## 构建

```bash
npm run build
```

## 风险提示

本项目仅用于策略研究和模拟记账，不构成投资建议。模拟收益不代表真实交易结果。
